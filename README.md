# Portfolio (Next.js 14, App Router)
1. `npm install && npm run dev`
2. Put 5 MP4s in `public/videos/`: hero.mp4, work-1.mp4 … work-4.mp4 (compressed, ~1080p, under 8 MB each, no audio needed).
3. Edit name, email, phone and copy at the top of `app/page.js`.
4. Deploy: push to GitHub and import in Vercel.
Until videos are added, a colour-gradient fallback shows.
